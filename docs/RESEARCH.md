# 入試物理の題材調査

調査日: 2026-11-14。一次資料はREADMEとアプリ内の原資料リンクに記録。問題文・図を複製せず、題材の概念、保存量、理想化と実装範囲を抽出した。

## 確認の粒度

1. **近畿大学公開教材**：PDF p2の問題図を確認。自由台4m、質点m、半径Lと2Lの左右非対称円弧、長さ2Lの水平部。これは可動曲面台という題材の根拠であり、2024年度入試の問題だとは断定しない。フォルダ名と教材年度から実施年を推定しない。
2. **千葉大学2019先進科学プログラム**：公式解答p2の式を確認。ばねによる分離の運動量・エネルギーと可動曲面台上の最高点。ばね、台を独立シーンへ分解。分離・台への乗り移りは未実装。
3. **都立大学2025後期**：出題意図PDF p4を確認。化学科・建築学科の物理第1問はばね二体系、第2問は導体棒と電磁誘導。具体的な原図やすべての初期条件を取得したとは扱わない。
4. **中部大学2023前期A/B・2月3日**：PDF p26–27、冊子p295–296の図と設問を確認。複数滑車・複数おもり、途中で糸を切る。本アプリの二段Atwoodとは原図のトポロジーが異なる。共通する学習要素は糸の拘束と張力関係である。
5. **名古屋工業大学2026前期**：公式解答／出題意図p1。滑車・糸・ばねの力学と電磁気。複合装置の厳密な再現と称さず、拡張候補の根拠として利用。
6. **京都大学2026**：理科問題PDF p3と出題意図PDF p2を確認。可動斜面と固定斜面、摩擦、二つの斜面、荷電粒子・衝突などを組み合わせる。今回の自由台／固定台の比較に関連するが、磁場中の粒子や二台の台を再現する実装ではない。

## 調査から決めた設計

- 見た目だけ似せるのでなく、自由台に勝手な固定力を加えないこと、床がある系で鉛直運動量を保存させないことを優先。
- 「球を落とす」と「曲面上から滑らせる」は別の初期条件。落下着地時の衝撃量と散逸を計算する。
- ばね二体系は重心と相対運動の分離が見えるようにする。重心追従カメラと物理量の参照系を混同しない。
- 導体棒は一定速度・手放し・一定力を区別。ジュール熱と外力の仕事を含めない保存則表示を避ける。
- 滑車は質量ゼロの動滑車の張力の関係と、糸の長さの係数を明示。拘束の破綻を隠してアニメーションだけ動かさない。
- 問題の全文・図は各大学の公開ページで読む。アプリは出題元を示した独自の学習モデル。
