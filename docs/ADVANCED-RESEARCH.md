## 指定テーマだが、特定入試への対応を断定していないもの

- **ミリカン油滴**：[3B Scientific実験書](https://www.3bs.jp/documents-download/UE5010400j.pdf)の力の内訳とStokes抵抗を参照。入試の大学・年度は未確定。Cunningham補正、ブラウン運動、蒸発は省略。
- **シンクロトロン／サイクロトロン**：[J-PARC RCS公式解説](https://www.j-parc.jp/c/facilities/accelerators/rcs.html)を参照。同じ円軌道を保つための磁場同期と、固定磁場で軌道が広がるサイクロトロンを区別する。同期加速は薄いRFギャップと基準軌道の写像であり、連続電磁場を解く実機モデルではない。
- **加速車からの投射、自由台車振り子、伸縮する弾性振り子**：ユーザー指定の主題を、明示した仮定の下で独自にモデル化。大学名・年度を捏造して紐付けない。

## 網羅マップ（実装済み／未実装を区別）

| 主題 | 実装済み | 次に必要な別モデル・未実装範囲 |
|---|---|---|
| 運動量・重心 | 自由曲面台、二体ばね、台車上の三体、自由台車振り子 | 糸切断後の二体回転、噴射・質量流入、複数回衝突 |
| 相対運動・慣性力 | 地上／台車の位置・速度変換、一定加速投射、加速支点、回転座標・コリオリ力 | エレベーターの接触離脱、回転する流体系、転がり接触 |
| 振動・振り子 | 単振り子の有限振幅・棒の回転、糸の張力限界、連成振り子、弾性振り子、三体ばね | 糸がたるんだ後の飛行・再緊張、物理振り子の慣性モーメント、強制・減衰振動、非線形共振の専用検証 |
| 摩擦 | ベルト単体／粗滑二体、静止→動摩擦→追従、熱・モータ仕事 | ばね台車と摩擦ブロック・壁衝突、転倒、摩擦を伴う転がり |
| 拘束 | 定滑車・動滑車・複合滑車、自由台・剛体棒 | 質量を持つ滑車、糸の切断・たるみ、可変長振り子 |
| 電磁気 | 導体棒の誘導・磁気抵抗、磁場円運動、サイクロトロン、理想同期軌道、油滴 | 交差電磁場・速度選別、二本の導体棒、LCR・コンデンサ結合、相対論・集束・位相安定性 |
| 剛体・回転 | 中心力の角運動量、質点の鉛直円運動 | 剛体三角形の支持切替、転倒、円柱転がり、慣性モーメント |
| 波・光・熱・原子 | 今回は未実装 | 干渉・回折、移動音源・ドップラー、レンズ、ピストン・熱サイクル、光電効果等 |

モデル数を増やすだけでなく、「接触状態の切替」「どの系でエネルギーを検証するか」「初期条件の許される範囲」を各モデルの登録条件とする。全入試範囲を網羅済みとはしていない。
