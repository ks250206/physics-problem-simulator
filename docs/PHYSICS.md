# 物理モデル・導出・検証

単位はSI。描画は3Dだが運動は各装置の理想的な平面内で拘束する。表示上の小球・箱・ばね・滑車の半径や太さに力学的な意味はない。

## 1. 自由曲面台と質点

台の水平位置をX、小球の台からの相対水平座標をq、高さをf(q)とする。x=X+q、y=f(q)。台は回転せず、床反力により鉛直移動しない。

```
K = 1/2 (M+m) Xdot² + m Xdot qdot + 1/2 m (1+f'²) qdot²
P = (M+m) Xdot + m qdot
β = M/(M+m)
qddot = -f' [g + f'' qdot²] / (β + f'²)
X = [m q0 + P t - m q] / (M+m)
N = m [g + f'' qdot² + f' qddot] sqrt(1+f'²)
```

Xの初期値0、台の初速度0。固定台はX=0、β=1に置換。自由台の水平運動量を式から再構成するため、独立にXを数値積分するドリフトを避ける。質点の鉛直運動量は床反力・重力があるので保存量ではない。

曲面はr=q/3として `f=.65+h r²`、`.65+h(r²+.28r³)`、`.65+h r⁴`。表示範囲|q|≤3は凹型で、これらの条件では接触反力は非負。RK4を表示サンプル1/60秒あたり8分割する。端に近づいたら停止し、端からの離脱・自由飛行は計算しない。

### 落下から接触

drop>0の初期条件では自由落下。初速度の水平成分v0、鉛直成分0。接触時刻を二分探索42回で求める。法線n=(-f',1)/sqrt(1+f'²)、接近法線相対速度vnに対して

```
J = -(1+e) vn / (1/m + nx²/M)
v_after = v_before + J n/m
V_after = V_before - J nx/M
```

固定台では分母のnx²/Mを除き、V=0。UIではe=0で接触後は滑走に移る。Q=K_before-K_afterを加え、K+U+Qが保存。衝撃中の床の鉛直力積を無視して鉛直運動量まで保存させてはいけない。滑走開始（drop=0）の初期鉛直速度はf'(q0)v0で、落下開始の条件とは異なる。

## 2. 永続的に連結されたばね二体系

μ=m1m2/(m1+m2)、ω=sqrt(k/μ)、r=ℓ0+A cosωt。初期相対速度0。

```
Xcm=Vt
x1=Xcm-m2 r/(m1+m2), x2=Xcm+m1 r/(m1+m2)
v1=V-m2 rdot/(m1+m2), v2=V+m1 rdot/(m1+m2)
E=1/2(m1+m2)V²+1/2 kA²
T=2π sqrt(μ/k)
```

原資料にある物体の分離や壁との衝突は扱わない。カメラの重心追従は数値の座標系変換ではない。

## 3. 導体棒・抵抗回路

水平レール面xz、棒はz方向、正のBは+y、棒速度+x。正電流は棒の+z向き。よってv×Bは+z、Iℓ×Bは-x。

```
c=(Bℓ)²/R, γ=c/m
ε=Bℓv, I=ε/R, Fmag=-cv
m vdot=Fext-cv
```

速度保持ではv=v0、Fext=cv0、Q=W=cv0²t。手放しはFext=0、一定力はFext=F。

```
z=γt, φ1=(1-exp(-z))/z, φ2=(1-φ1)/z
v=v0 exp(-z)+(F/m)tφ1
x=v0 tφ1+(F/m)t²φ2
W=Fx, Q=W-1/2 m(v²-v0²)
```

z≈0ではφのTaylor展開を使い、B=0での0除算と桁落ちを避ける。γ>0で終端速度F/c。数値実装Qをエネルギー収支から計算するだけでは独立な検証にならないので、テストでは別途Simpson積分した∫I²Rdtと比較する。自己インダクタンスを無視するので、導体棒の変化に電流が瞬時追従する理想化。

## 4. 理想滑車の拘束条件

下向き座標yi。糸長の有効拘束はΣJi Δyi=0。各質点に作用する上向き張力はJi T。質量のない動滑車に加わる力のつり合いから係数を得る。

```
mi ai=mi g-Ji T
ΣJi ai=0
T=g ΣJi / Σ(Ji²/mi)
```

定滑車J=(1,1)、動滑車J=(1,2)。二段では上側の糸がm1と動滑車軸を結び、下側の糸がm2,m3を結ぶ。上側張力2T、下側T、J=(2,1,1)。下側滑車座標yp=4-y1、下側糸はy2+y3-2yp=一定。初速度0なので位置と速度は等加速度の解析解。

可動範囲、床との接近、おもりと滑車の接近の最初の時刻を解き、その時刻で停止。衝突を無視したまま装置を貫通させない。重力ポテンシャルmi g(5.2-yi)とKの和は一定。支点は外力を加えるので総運動量の保存は要求しない。

## 数値指標

各サンプルにK,U,Q,W,p,constraintとモデル別のextraを持つ。収支の規格化は max(1 J,|E0|) による。E0≈0で相対誤差が発散するのを避けるため、この量は厳密な相対誤差ではなく規格化収支誤差。曲面台だけ数値積分、その他は解析解。共有URLの数値はUIの範囲にclampし、NaN・不明なモデル選択は採用しない。
