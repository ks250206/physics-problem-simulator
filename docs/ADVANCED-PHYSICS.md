# 追加10モデルの導出・数値手法

計算はSI単位。描画の拡大率・物体の外形サイズ・矢印長は物理計算に影響しない。座標系を切り替えてもエネルギー収支は常に地上系の `K+U+Q−W` を表示する。

## 1. 台車上の二物体：三体・二ばね

台車位置X、物体位置x1,x2。左壁X−3、各ばね自然長2なので、伸びはe1=x1−X+1、e2=x2−x1−2。

- M Ẍ = k1 e1 + F
- m1 ẍ1 = −k1 e1 + k2 e2
- m2 ẍ2 = −k2 e2

固定時はẌ=Ẋ=0。一定外力モードの仕事はF(X−X0)。自由系では全水平運動量と重心の等速運動を検証。台車系の実座標はxi′=xi−X、相対速度vi′=vi−Ẋ、表示合力に−miẌを追加。壁・物体の接触面をイベント検出して停止する。

## 2. 台車振り子

棒角θを鉛直下から測り、小球位置は(X+Lsinθ,H−Lcosθ)。一般化質量行列から

```
(M+m)Ẍ + mLcosθ θ̈ = −kX + mLsinθ θ̇²
Lθ̈ + cosθ Ẍ + gsinθ = 0
```

自由／ばね台車では `Ẍ = (−kX+mLsinθ θ̇²+mgsinθcosθ)/(M+m sin²θ)`。
強制加速aではẌ=aを指定し、外部駆動力 `(M+m)a + mL(cosθ θ̈−sinθ θ̇²)` と台車速度の積を積分してWを求める。つり合い角は−atan(a/g)。棒の軸力はm(gcosθ−a sinθ+Lθ̇²)。棒は圧縮を許す。

## 3. 単振り子と糸の張力限界

`θ̈=−g sinθ/L` を有限振幅のまま積分。棒なら軸力の符号を問わず回転可能。糸なら `T=m(gcosθ+Lθ̇²)` が0に達した時刻を二分探索して停止する。初期からT≤0ならt=0で停止。これは飛行・再緊張を黙って円運動に置き換えないための境界である。

## 4. 連成振り子

固定支点間距離D=3 m、自然長Dの連結ばね、棒の長さL。実際の小球間ベクトルdから力 `k(|d|−D)d/|d|` を求め、各棒の接線方向へ射影して角加速度を求める。近似式ではなく幾何学的に正しい有限振幅系。

等質量・小角極限で `ω同相²=g/L`、`ω逆相²=g/L+2k/m`。E1/E2は各球の運動＋重力位置エネルギーで、ばねエネルギーは別計上。

## 5. 弾性振り子

支点を原点とする位置rベクトルで `m r̈ = −k(|r|−L)r/|r| + (0,−mg)`。極座標の式は学習用に表示するが、計算はデカルト座標。支点付近での特異性と床の衝突前に停止。鉛直だけの運動が独立した単振動の解析解と一致することを検証。

## 6. ベルト上の二物体：ハイブリッド系

斜面上向きを正、Aを上側、Bを下側とする。e=xA−xB−2、Bは摩擦なし。

```
mA aA = f − ke − mA g sinα
mB aB = ke − mB g sinα
```

滑り中はf=−μkN sgn(vA−V)。追従中はvA=Vを拘束し、必要な摩擦f必要=ke+mAgsinαが最大静止摩擦を超えると離脱。

- 相対速度が符号を変える接触だけでなく、**相対速度が極値でちょうど0に触れる接触**も検出。東大型の釣り合い初期条件は後者で、符号変化だけの実装では追従を見落とす。
- 初期条件 mA=mB=1, k=5, α=15°、μk=2tanα、e0=mg sinα/k、vA0=0, vB0=V=.9 では最初の追従時刻はπ/√(2k/m)≈0.99346 s。
- 仕事はẆ=fV、熱はQ̇=μkN|vA−V|。これらを独立の状態変数として積分し、エネルギー差から熱を作らない。
- 静止摩擦の上限はmax(μs,μk)N。ユーザーがμs<μkを選んだ場合の解釈を明示。
- 単体水平ベルトでは停止状態からの捕捉時刻V/(μkg)、最終K=Q=mV²/2、W=mV²を独立に照合。

## 7. 加速台車からの投射

ボールは地上系で等速水平運動と鉛直放物運動。車位置X=V0t+at²/2と引き算して車系へ変換。慣性力−maは車系でのみ表示し、地上系の運動方程式には加えない。投射原点の基準面までで停止。

## 8. 回転座標と中心ばね

地上系の力は0または自然長Lの中央ばね。表示時にr′=R(−Ωt)r、v′=R(−Ωt)v−Ω×r′へ変換。

コリオリ力−2mΩ×v′と遠心力−mΩ×(Ω×r′)は表示用の回転系の力であり、地上系の積分に二重加算しない。自由粒子の回転系加速度を位置の二階差分と照合。中央ばねでは地上系の角運動量を検証。

## 9. 磁場・加速器の写像

非相対論的正電荷、Bはxy平面の手前。ギャップの間は磁場内の厳密円弧、角速度qB/m。

- 一様磁場だけ：磁気力の仕事0、速度一定。
- サイクロトロン：x=0の薄いRFギャップで半周ごとにKをqV増加。円弧の中心はその都度正しく更新され、単なる半径増加スパイラルの描画ではない。
- シンクロトロンの理想基準軌道：1周ごとにRFキック、その直後にB=mv/(qR)と周回時間を更新し、同じ半径Rの基準軌道を維持。

**後者は実機の連続場モデルではない。** 瞬時磁場変更に伴う誘導電場、磁場ランプ、RF位相安定性、集束、放射、相対論は解かない。この範囲を画面・調査記録にも明記。モードを「シンクロトロン」と名付けただけでサイクロトロンと同一の運動を表示しない。

## 10. ミリカン油滴

rはμm入力をmに、dはmm入力をmに変換。油質量m=(4πr³/3)ρ、浮力補正後の重力G=(4πr³/3)(ρ−ρair)g、b=6πηr。

```
τ=m/b、v∞=(qV/d−G)/b
v(t)=v∞(1−exp(−t/τ))
Δy=v∞[t−τ(1−exp(−t/τ))]
Q=bv∞²[t−2τ(1−exp(−t/τ))+τ/2(1−exp(−2t/τ))]
W=q(V/d)Δy、U=Gy
```

微小なτを固定ステップで無理に積分せず解析解を用いる。短時間の相殺誤差はexpm1と級数で回避。油滴中心が電極から半径rの距離に達した時刻を二分探索。e=1.602176634e−19 C、電荷数は整数。

エネルギーの計算はJ、グラフのみfJに換算。誤差の規格化基準はmax(初期|K|+|U|, 全時刻|W|, 1e−30 J)。従来のmax(1 J, |E0|)を適用して微小量の誤差を隠さない。

## 数値積分・CSV

一般の滑らかなモデルはRK4・内部ステップ最大1/960 s、摩擦系は最大1/1200 s。描画用の出力は60 Hz。接触・張力境界は必要に応じて内部時刻を二分探索する。ベルト区間端・物体接近は内部刻み以内で停止。

CSVは全自由度とextra観測量を出力。q/vはモデルごとに以下の順。

| id | q | v |
|---|---|---|
| cartSpring | X,x1,x2 (m) | V,v1,v2 (m/s) |
| cartPendulum | X (m), θ (rad) | V (m/s), ω (rad/s) |
| pendulum | θ (rad) | ω (rad/s) |
| coupledPendulum | θ1,θ2 (rad) | ω1,ω2 (rad/s) |
| elasticPendulum | 支点原点x,y (m) | vx,vy (m/s) |
| conveyor | 斜面方向xA,xB (m) | vA,vB (m/s) |
| relative | X車,x球,y球 (m) | V車,vx球,vy球 (m/s) |
| rotating | 地上系x,y (m) | 地上系vx,vy (m/s) |
| accelerator | x,y (m) | vx,vy (m/s) |
| millikan | 下電極からの高さ (m) | 上向き速度 (m/s) |

pは水平運動量の検証に使用するモデルでのみ意味がある。非対象モデルは0を入れ、運動量の保存表示をしない。全モデルのQ,W,K,Uは地上系で定義。
